# 2026-02-05

## 目标
- 修改中国队列 merge 脚本，生成新的 SA7/SA17/Yeo7 数据（输入路径与字段以 `V2nd_mergedata_Yeo_sumSC_ChineseCohort.R` 为准）。
- 所有输出写入当前 `SCDevelopment` 项目路径，并提供一个 `sbatch` 脚本一键生成三种结果。

## 关键变更
- `development_script/1st_dataclean/merge_Chinese_cohort/S2nd_mergedata_SA_ds_sumSC_ChineseCohort.R`
  - 支持 `--ds_res=<7|17|...>`，用于生成 SA7/SA17（原脚本固定 SA12）。
  - 运行环境不再依赖 `getwd()` 是否包含 `cuizaixu_lab`；改为检测 `/ibmgpfs` 以适配容器内 `/work` 工作目录。
  - 输入（SC mat/volume/demography/index/deleteindex）保持为既有 GPFS 绝对路径；输出目录改为项目内 `outputs/intermediate/1st_dataclean/chinese_cohort/`（可用 `--output_dir` 覆盖，且必须在项目内）。
  - 统一 phenotype 合并列（对齐 Yeo 脚本），并对缺失列自动填充 `NA`。
  - 默认 `--make_plots=0`，仅生成 `.rds`；如需生成矩阵图与稀疏度统计，可设 `--make_plots=1`。
- `development_script/1st_dataclean/merge_Chinese_cohort/V2nd_mergedata_Yeo_sumSC_ChineseCohort.R`
  - 支持 `--yeo_res=<7|17>`；本次生成目标为 `--yeo_res=7`（输出文件名仍为 `SCdata_Yeo7_*`，对应 limbic 删除后的有效节点数）。
  - 同样修复容器内路径判断与输出路径（写入当前项目 `outputs/intermediate/1st_dataclean/chinese_cohort/`）。
  - 默认 `--make_plots=0`。
- 修复 `rbind` 列数不一致报错：在 SA/Yeo 两个脚本中统一 phenotype 合并列（`subID/Age/Sex/Handedness/CBCLtotalproblem/EFPCA/ICV/mean_fd`），缺失列自动填充 `NA`，保证 `rbind` 列数一致。
- 修复 `dplyr::rename()` 的重复列名报错：当 CCNP 表已包含 `subID` 时，跳过 `scanID -> subID` 的重命名，并删除潜在重复源列。
- 修复中国队列 merge 的 node volume 读取：改用 `read.table(..., fill=TRUE)` 忽略 `missing label` 等非数值行；仅保留前 400 个数值，并在 volume 文件缺失或长度不足时给出 warning 并跳过该被试。
- CuiBP demopath 改为读取项目内 `demopath/basic_demo_merge_screen.xlsx`（SA/Yeo merge 两个脚本一致）。
- 中国队列 devmodel（ComBat-GAM）脚本增加 `--ds_res`/`--out_tag` 支持，输出文件名与图像文件名可按 SA7/SA17 区分，避免覆盖 SA12。
- 中国队列 changerate S-A corr 脚本增加 `--ds_res`/`--out_tag`，输出目录改为 `CV75_<tag>/` 并同步更新图像命名。
- 新增中国队列 Yeo7 ComBat-GAM devmodel/changerate 脚本（基于 HCP-D 版本改写为 chinese 路径）。
- 新增中国队列 SA7/SA17/Yeo7 的 devmodel 与 changerate 容器版 sbatch 提交脚本。
- 新增中国队列 SA7/SA17/Yeo7 的 ComBat-GAM sbatch 提交脚本（默认输入来自 `outputs/intermediate/1st_dataclean/chinese_cohort/`，输出到 `outputs/results/combat_gam/chinese/`）。
- 修复中国队列 devmodel S3 在 SA7/SA17 的 S-A rank/decile 计算：矩阵维度改为 `ds_res`，并将 decile CSV 命名为 `<out_tag>_10.csv` 以避免覆盖。
- 中国队列 SA7/SA17 的 devmodel/changerate 脚本新增 `skip_euclid` 分支，默认跳过 Euclidean distance 控制（无对应距离文件）。
- 新增一键脚本：`sbatch/run_chinese_merge_SA7_SA17_Yeo7_container.sbatch`
  - 顺序生成 SA7、SA17 与 Yeo7 的 merge RDS（容器环境）。
  - 默认输出：`outputs/intermediate/1st_dataclean/chinese_cohort/`。
