# 2026-02-09

## 目标
- 解释中国队列 merge 缺少 CCNP 的原因，并修复。
- 在中国队列 merge 中剔除年龄 > 26 的被试。

## 结论与修复
- CCNP 缺失原因：`basic_demo_devCCNPPEK.csv` 同时包含 `subID` 与 `scanID`，脚本为避免重复列名保留了原 `subID`（不含 `ses-XX`），从而生成的 SC/volume 文件名不匹配实际文件（实际文件名包含 `scanID` 的 session），导致 `file.exists` 不通过而跳过 CCNP。
- 修复：当存在 `scanID` 时删除旧 `subID` 并以 `scanID` 作为 `subID`，使文件名与实际 CCNP 文件匹配。
- 增加年龄筛选：在合并 `Behavior` 后剔除 `Age > 26` 的被试。
- 对齐 reference：SA/Yeo merge 的 CCNP/scanID 处理、行为表型合并列、node volume 读取逻辑与 reference 脚本一致。
