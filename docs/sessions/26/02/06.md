# 会话记录（2026-02-06）

## 目标
- 基于现有 age_wp/age_bp interaction 脚本，为 cognition 与 pfactor 生成新脚本。
- 将年龄分解改为：`age_bp=baseline age`，`age_wp=current age - baseline age`。
- pfactor 改为仅使用基线值（`GENERAL_base`），与 cognition 的 baseline 方案对齐。
- 在 cognition/pfactor 新脚本中同时实现两类交互模型：
  - `y ~ age_wp * cov + age_bp + sex + mean_fd + (1 | subID)`
  - `y ~ age_wp + age_bp * cov + sex + mean_fd + (1 | subID)`
- 增加“先在 decile 内聚合 SC ratio，再拟合交互模型”的流程，并绘制 age_wp 与 age_bp 在 low/high 下的 10 decile 差异图（含 2×5 拼接图）。

## 代码变更
- 新增 `development_script/5th_cognition/run_abcd_lmm_agewp_agebp_baselineage_cognition_interaction_decileavg.R`：
  - 从基线访视提取 `age_bp`，定义 `age_wp = age - age_bp`。
  - cognition 使用 baseline-only `nihtbx_fluidcomp_uncorrected_base`。
  - 同时拟合 `age_wp*cov` 与 `age_bp*cov` 两类随机截距模型。
  - 实现两套绘图流程：
    - edge-first：逐边拟合后在 decile 内平均预测曲线；
    - decile-avg-SC-first：先聚合 `SC_decile1~10` 再拟合模型。
  - 输出 age_wp 与 age_bp 两组 low/high 的 10 decile 曲线图（含 2×5 总图），不输出 t 值矩阵。
- 新增 `development_script/6th_pfactor/run_abcd_lmm_agewp_agebp_baselineage_pfactor_interaction_decileavg.R`：
  - 与 cognition 同构流程，pfactor 改为 baseline-only `GENERAL_base`。
  - 线型按既有流程保持 low pfactor 为实线、high pfactor 为虚线。
