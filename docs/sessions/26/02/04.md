# 2026-02-04

## 目标
- 为 ABCD 的 SA7/SA17/Yeo7 生成 Nonlinear ComBat-GAM（combat）、devmodel（S1–S4）与 changerate（沿年龄 alignment）的 `sbatch` 提交脚本。
- 约束：仅提供可复用 `sbatch` 脚本与明确提交命令；不在会话中直接提交 `sbatch` 作业。

## 变更摘要
- 新增 `sbatch/` 脚本（容器版）：
  - combat：`sbatch/run_abcd_combatgam_{SA7,SA17,Yeo7}_CV75_container.sbatch`
  - devmodel（S1–S4）：`sbatch/run_abcd_devmodel_combatgam_{SA7,SA17,Yeo7}_CV75_container.sbatch`
  - changerate：`sbatch/run_abcd_changerate_sacorr_combatgam_{SA7,SA17,Yeo7}_CV75_container.sbatch`
- 修复/增强脚本参数化与可复现性：
  - `combat_gam/scripts/run_abcd_nonlinear_combat_gam.R`：输出文件名不再固定为 SA12；改为依据输入文件名自动生成对应的 `SCdata_<tag>_...combatgam_<variant>.rds`（例如 SA7/SA17/Yeo7）。
  - `development_script/2nd_fitdevelopmentalmodel/S2nd_calculatederivative_ABCD_combatgam.R`：新增 `--ds_res`（默认 12）支持，用于 SA7/SA17/Yeo7 的 derivative 计算。
  - `development_script/2nd_fitdevelopmentalmodel/S1st_fitgammodels_SA_ds_sumSCinvnode_ABCD_combatgam.R`：支持 `--ds_res`，并从输入 `SC.*_h` 列数推断 `elementnum` 以匹配不同分辨率（同时避免跨分辨率覆盖 `baseline_fits/failed_edges` 文件名）。
  - `development_script/2nd_fitdevelopmentalmodel/S3rd_visualizationfitSCcurves_SA12sumSCinvnode_ABCD_combatgam.R`：支持 `--ds_res` 与 `--out_tag`，用于 SA7/SA17/Yeo7 的绘图与 decile 产物命名。
  - `development_script/2nd_fitdevelopmentalmodel/S4th_correlationTo_SArank_SA12sumSCinvnode_ABCD_combatgam.R`：
    - 新增 `--ds_res`（默认 12）与 `--out_tag`（用于避免覆盖不同分辨率的 summary）。
    - `--euclid_csv` 变为可选：未提供或不存在时自动跳过“控制欧氏距离”的残差化与相关统计。
  - `development_script/4th_changerate_SAcorr/S1st_SAcorr_alongAge_ABCD.R`：支持 `--ds_res` 与 `--out_tag`，并将输出写入带后缀的目录以避免覆盖不同分辨率结果。
  - `sbatch/run_abcd_changerate_sacorr_combatgam_CV75_container.sbatch`：支持 `DS_RES/OUT_TAG`，并按分辨率检查/生成 derivative 产物。
  - `combat_gam/longitudinal/nonlinearlongcombat.R`：移除未使用的 `library(invgamma)` 依赖，避免在计算节点/容器环境中因缺包直接中止。

## 备注
- devmodel 脚本内部顺序运行 S1–S4，不再拆分为单步脚本。
- changerate 脚本会在缺失 derivative 产物时自动补跑上游 S1/S2。
- S4 的 `EUCLID_CSV` 默认为未设置；如需要控制距离残差化，请在提交时显式提供 `EUCLID_CSV=/path/to/average_EuclideanDistance_<ds>.csv`。
- Yeo7 默认 `DS_RES=6`（对应“去 limbic”的 6 节点版本，edge=21）；若你的 Yeo7 边数为 28，请在 devmodel/changerate 提交时设置 `DS_RES=7`。
